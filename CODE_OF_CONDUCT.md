# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code rather than people, and do not
harass. Maintainers may edit or remove contributions and comments that violate the covenant,
and may ban contributors for repeated or severe violations.

Report incidents privately to the maintainer (see the GitHub profile of
[@enderliker](https://github.com/enderliker)). Reports are handled confidentially.
